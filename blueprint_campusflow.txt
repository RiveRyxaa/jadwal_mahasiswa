
BLUEPRINT APLIKASI SOBATKULIAH
===============================

NAMA APLIKASI:
SobatKuliah

JENIS APLIKASI:
Aplikasi Mobile Jadwal Kuliah Pintar & Produktivitas Mahasiswa (Android)

TARGET PENGGUNA:
- Mahasiswa universitas
- Mahasiswa aktif kuliah
- Mahasiswa dengan jadwal padat

==================================================
1. TUJUAN UTAMA APLIKASI
==================================================

Aplikasi ini membantu mahasiswa untuk mengatur:
- Jadwal kuliah mingguan
- Deadline tugas dengan prioritas
- Notifikasi pengingat otomatis (15 menit & tepat waktu masuk kelas)
- Pengingat deadline tugas (1 hari, 3 jam, 1 jam sebelum)
- Produktivitas harian

Tujuan utama:
Membantu mahasiswa menjadi lebih terorganisir dan tidak lupa jadwal atau tugas
dengan sistem notifikasi pintar yang berjalan di latar belakang.

==================================================
2. FITUR UTAMA (SUDAH DIIMPLEMENTASI)
==================================================

[1] AUTENTIKASI (Firebase Auth)
-------------------------------
Fitur:
- Register akun (email/password)
- Login akun (email/password)
- Login dengan Google
- Lupa password (reset via email Firebase SMTP)
- Auto login (session tersimpan)
- Keluar (logout)

Data pengguna:
- Nama lengkap
- Email
- Password (terenkripsi Firebase)
- Universitas
- Jurusan

Catatan:
- SMTP dikonfigurasi melalui Firebase Console
- Menggunakan Gmail App Password untuk pengiriman email
- Link reset password masuk ke inbox utama (bukan spam)

==================================================

[2] DASHBOARD (Beranda)
-----------------------
Menampilkan:
- Kelas berikutnya dengan countdown waktu
- Jadwal hari ini (dengan badge BERLANGSUNG jika sedang berjalan)
- Tugas mendatang (3 terdekat)
- Statistik: IPK rata-rata & jumlah tugas selesai
- Tombol notifikasi → buka halaman notifikasi
- Navigasi cepat ke semua fitur

Contoh tampilan:
--------------------------------
KELAS BERIKUTNYA
Basis Data
09:00 - Ruang A204
Mulai dalam 1j 12m
--------------------------------

==================================================

[3] MANAJEMEN JADWAL KULIAH
----------------------------
Fitur:
- Tambah jadwal kuliah
- Edit jadwal
- Hapus jadwal (long press + konfirmasi)
- Tampilan jadwal mingguan (Senin-Sabtu)
- Selector hari dengan tanggal
- Badge "SEDANG BERLANGSUNG" untuk kelas aktif
- Kode mata kuliah otomatis

Input:
- Nama mata kuliah
- Nama dosen
- Hari (dropdown: Senin-Sabtu)
- Jam mulai (time picker)
- Jam selesai (time picker)
- Ruangan
- Catatan (opsional)

Penyimpanan: SharedPreferences (JSON lokal)

==================================================

[4] TRACKER TUGAS
-----------------
Fitur:
- Tambah tugas
- Edit tugas
- Hapus tugas (long press + konfirmasi)
- Atur deadline (date & time picker)
- Tandai tugas selesai/aktif (toggle checkbox)
- Label prioritas dengan warna
- Pengelompokan berdasarkan prioritas
- Badge status: TINGGI, SEDANG, RENDAH, SELESAI, TERLAMBAT

Level prioritas:
- Tinggi (merah)
- Sedang (oranye)
- Rendah (hijau)

Statistik:
- MENDESAK (jumlah tugas prioritas tinggi/terlambat)
- SEDANG DIKERJAKAN (jumlah tugas aktif)
- SELESAI (jumlah tugas selesai)

Penyimpanan: SharedPreferences (JSON lokal)

==================================================

[5] SISTEM NOTIFIKASI (flutter_local_notifications)
----------------------------------------------------
Notifikasi push otomatis (muncul di layar HP meskipun app tertutup):

Jadwal Kuliah:
- 📚 15 menit sebelum kelas dimulai
- 🔔 Tepat saat waktu kelas dimulai
- Repeat otomatis setiap minggu

Deadline Tugas:
- ⏰ 1 hari sebelum deadline
- 🔴 3 jam sebelum deadline (khusus prioritas tinggi)
- 🚨 1 jam sebelum deadline

Fitur teknis:
- Notifikasi dijadwalkan ulang otomatis saat tambah/edit/hapus data
- Tetap aktif setelah HP restart (BootReceiver)
- Exact alarm scheduling (Android 12+)
- Permission POST_NOTIFICATIONS (Android 13+)
- Timezone Asia/Jakarta

Halaman Notifikasi:
- Daftar pengingat aktif berdasarkan urgensi
- Jadwal hari ini & besok
- Tugas terlambat, deadline hari ini, minggu ini
- Tombol "Tandai Dibaca"

==================================================

[6] PROFIL & PENGATURAN
-----------------------
Fitur:
- Edit profil (nama, universitas, jurusan)
- Ganti password
- Mode Terang / Mode Gelap (toggle switch)
- Hubungi Kami (form kontak via email)
- Keluar (logout dengan konfirmasi)

Halaman Hubungi Kami:
- Form: Nama, Email, Subjek (dropdown), Pesan
- Kirim via intent email (mailto)
- Subjek: Bug, Saran, Pertanyaan Umum, Lainnya

==================================================

[7] TEMA (Dark Mode / Light Mode)
----------------------------------
Pilihan tema:
- Mode Terang (default)
- Mode Gelap

Konsep desain:
- Modern & premium
- Warna utama: Ungu (#6C63FF / #1B365D)
- Glassmorphism cards
- Animasi transisi halus
- Google Fonts: Inter
- Seluruh teks dalam Bahasa Indonesia

Penyimpanan: SharedPreferences (otomatis tersimpan)

10. ANDROID PERMISSIONS
==================================================

- POST_NOTIFICATIONS (izin tampilkan notifikasi, Android 13+)
- RECEIVE_BOOT_COMPLETED (notifikasi aktif setelah HP restart)
- SCHEDULE_EXACT_ALARM (jadwalkan notifikasi tepat waktu)
- USE_EXACT_ALARM (alarm tepat, Android 12+)
- VIBRATE (getar saat notifikasi)
- WAKE_LOCK (layar aktif saat notifikasi)

Receiver:
- ScheduledNotificationBootReceiver (reschedule setelah reboot)
- ScheduledNotificationReceiver (terima notifikasi terjadwal)
