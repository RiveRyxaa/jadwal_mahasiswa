
BLUEPRINT APLIKASI CAMPUSFLOW
=============================

NAMA APLIKASI:
CampusFlow

JENIS APLIKASI:
Aplikasi Jadwal Kuliah Pintar & Produktivitas Mahasiswa

TARGET PENGGUNA:
- Mahasiswa universitas
- Mahasiswa aktif kuliah
- Mahasiswa dengan jadwal padat

==================================================
1. TUJUAN UTAMA APLIKASI
==================================================

Aplikasi ini membantu mahasiswa untuk mengatur:
- Jadwal kuliah
- Deadline tugas
- Reminder kegiatan
- Produktivitas harian

Tujuan utama:
Membantu mahasiswa menjadi lebih terorganisir dan tidak lupa jadwal atau tugas.

==================================================
2. FITUR UTAMA (VERSI MVP)
==================================================

[1] AUTENTIKASI
---------------
Fitur:
- Register akun
- Login akun
- Logout
- Lupa password

Data pengguna:
- Nama lengkap
- Email
- Password
- Universitas
- Jurusan

==================================================

[2] DASHBOARD
-------------
Menampilkan:
- Jadwal hari ini
- Kelas berikutnya
- Deadline tugas terdekat
- Countdown menuju kelas berikutnya

Contoh:
--------------------------------
Kelas Berikutnya:
Basis Data
09:00 - Ruang A204

Dimulai dalam:
1 jam 12 menit
--------------------------------

==================================================

[3] MANAJEMEN JADWAL KULIAH
---------------------------
Fitur:
- Tambah jadwal kuliah
- Edit jadwal
- Hapus jadwal
- Tampilan jadwal mingguan

Input:
- Nama mata kuliah
- Nama dosen
- Hari
- Jam mulai
- Jam selesai
- Ruangan
- Catatan

==================================================

[4] TRACKER TUGAS
-----------------
Fitur:
- Tambah tugas
- Atur deadline
- Tandai tugas selesai
- Label prioritas

Level prioritas:
- Tinggi
- Sedang
- Rendah

==================================================

[5] SISTEM REMINDER
-------------------
Notifikasi:
- Kelas dimulai 30 menit lagi
- Deadline tugas besok
- Event kampus penting

Jenis reminder:
- Notifikasi browser
- Email reminder

==================================================

[6] DARK MODE
-------------
Pilihan tema:
- Light mode
- Dark mode

Konsep desain:
- Minimalis
- Modern
- Nyaman untuk mahasiswa

==================================================
